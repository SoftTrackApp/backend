# backend
SoftTrack backend service 🚀

## Введение

SoftTrack – сервис поведенческого анализа и мониторинга soft skills.  
С помощью SoftTrack наблюдателям можно в реальном времени фиксировать конкретные действия участников, которые автоматически связываются с их профилем компетенций.  
На основе полученных данных формируются дашборды для визуализации прогресса.  

Цель – фиксация и систематизация реальных проявлений навыков человека в течение его учебной и профессиональной деятельности.

Целевая аудитория – учебные заведения, HR-отделы организаций.

Каждая организация-партнер получает отдельный, изолированный экземпляр системы, который развертывается на ее собственной инфраструктуре.

## Ключевые определения

Soft skills (англ. «гибкие/мягкие навыки») / софт-скиллы:  комплекс умений общего характера, тесно связанных с личностными качествами.

Администратор системы: уполномоченное лицо, ответственное за настройку системы, создание учетных записей и последующую передачу учетных данных пользователям.

Дашборд: информационная панель, отображающая ключевые метрики и аналитику развития компетенций в наглядном графическом виде

Доска: рабочее пространство для фиксации поведений

Наблюдатель: пользователь-создатель доски

Субъект: пользователь, чье поведение фиксируется наблюдателем на доске

## Список прав

1. Редактирование профилей (ФИО, роль)  
2. Формирование/редактирование/удаление групп людей  
3. Создание/редактирование(название,связь с поведениями)/удаление софт-скилла,   
создание/редактирование(название,связь с софт скиллами)/удаление поведения,  
создание/редактирование(название, наполнение)/удаление набора поведений  
4. Оценивание пользователей (создание доски+отметить поведение+оставить комментарий)  
5. Просмотр собственного дашборда  
6. Просмотр всех дашбордов + просмотр комментариев

## Роли и их права

Руководитель: Все  
Психолог/Методист: Все, кроме 1 и 2   
Преподаватель/Аудитор: 4 и 5  
Ученик/Сотрудник: только 5   

Названия ролей и их права могут меняться в зависимости от нужд конкретной организации

## Регистрация, аутентификация и авторизация

Формы для регистрации в сервисе нет. Регистрация пользователей производится администратором системы.  
Передача логинов и паролей осуществляется вне системы (устно, через почту/мессенджер, в распечатанном виде и т.п.)

## Управление пользователями

Пользователь с соответствующими правами на странице “Управление пользователями” может редактировать учетные записи (ФИО?, роль). Найти нужного пользователя можно по ФИО в поисковой строке.  
После выбора пользователя появится кнопка “посмотреть дашбоард”, по которой можно перейти на страницу с дашбордом выбранного пользователя.  
Также на странице “Управление пользователями” можно посмотреть список существующих групп пользователей, изменить их, удалить или же создать новые группы.

## Управление навыками

На странице “Управление навыками” можно посмотреть список существующих поведений (есть поисковая строка), изменить их, удалить или создать новые.  
При создании новых будет необходимо привязать поведение к наборам поведений и софт-скиллам. 

На этой же странице можно посмотреть список наборов поведений, изменить их, удалить или создать новые. 

На этой же странице можно посмотреть список софт-скиллов, изменить их, удалить или создать новые.

## Работа с доской

На главной странице наблюдатель может нажать на кнопку «Доска». Параметры доски, которые нужно ввести: название, группа пользователей, набор поведений. Все обязательны. Параметры можно менять в процессе работы.  

На странице с доской наблюдатель может оценить субъект, связав его имя с поведением. У полей со списком субъектов и поведений есть строка поиска. К записи можно добавить комментарий.   

Поставленную на доске запись можно удалить (выводится список проставленных записей).   

Проставленные записи отображаются по 10 за раз, от новых к старым. 

## Дашборд

На дашборде отображается статистика по записям в виде гистограммы с накоплением.  

Каждое поведение представляет собой проявление нескольких софт-скиллов.  
На диаграмме отображается, сколько раз пользователь проявил определенный софт-скилл и долю (количество) каждого поведения, составляющего этот софт-скилл.  
Отображаются только те поведения, по которым у пользователя есть записи. 

Подробности по каждой записи (автор, комментарий, время) видны только пользователям с соответствующим правом.
